# 导入与分级预览验证（2026-11-01）

对比基线为合并导入优化前的 `74e52f6`。所有输入由脚本合成，使用隔离数据库；没有读取或上传私人媒体。

## 两次本机对比

| 场景 | 优化前 | 优化后 |
|---|---:|---:|
| 已有 10,000 条记录，新增 1,000 个文件的扫描 | 23.354–24.099 秒 | 0.189–0.190 秒 |
| 上述扫描使用的数据库连接 | 6,006 次 | 6 次 |
| 1,000 个未变化文件的补扫 | 9.799–10.014 秒 | 0.111–0.116 秒 |
| 未变化补扫使用的数据库连接 | 2,006 次 | 6 次 |
| 24 张 4800×3200 JPEG，首张可浏览 | 0.231–0.245 秒 | 0.101–0.115 秒 |
| 24 张 JPEG 全部可浏览 | 5.167–5.214 秒 | 1.202–1.250 秒 |
| 24 张 JPEG 全部标准预览完成 | 5.167–5.214 秒 | 4.370–4.414 秒 |

扫描部分仅测目录登记，不包含预览和哈希。预览部分使用独立目录，先完成登记，再计时预览队列；优化后采用默认照片并发 2，基线为串行。两级预览使“全部可浏览”早于“全部标准预览完成”，并没有省略后者。

这是暖文件系统缓存、合成同内容 JPEG 的小样本结果，不代表真实 RAW、HEIC、视频、网络盘、机械硬盘或大规模混合图库的总体吞吐量。特别是扫描提速倍数不能直接用于估算含媒体解码的整次导入。

## 复现

在项目根目录、已安装依赖的 `localmedia-v2` Conda 环境中运行；输出目录必须是全新路径。

```powershell
python scripts/benchmark_import.py --output work/import-benchmark-new
```

用 `--source-root` 指向基线源码导出目录，即可用相同脚本测旧实现；该目录需包含 `localmedia` 包。默认合成 1,000 个导入文件、10,000 条已有记录及 24 张大 JPEG。脚本不会发出模型请求。

## 正确性覆盖

- 首项提交后即对其他连接可见；未变化文件不写回媒体表。
- 快速缩略图与标准预览分开，尺寸和 EXIF 方向正确；AI 输入保持标准预览。
- RAW 内嵌预览路径不解包完整 RAW；缺少内嵌预览时延后到标准阶段。
- 旧图库直接沿用已生成的预览，按需迁移新增字段和索引。
- 当前视口和详情优先，关闭/离开后的优先级到期；大型视口仍为后台项目保留处理机会。
- 视频阻塞时照片仍可完成；图片/视频并发分别受限。
- 文件变化或目录删除发生在渲染途中时，旧结果不能发布；原文件不被删除。
- 单项标准预览完成后即可计算哈希，无须等待其他项目；视频预览子进程可取消。

RAW 部分使用协议替身验证调用顺序，不代表所有真实相机编码变体都已验收。
